PDF Extractor API

Extract text from PDF documents and receive structured JSON data organized page by page.

Open Swagger UI

01

Overview

The PDF Extractor API accepts PDF files, extracts text from each page, and returns structured JSON data.

Base URL http://127.0.0.1:8000
02

Authentication

PDF extraction is available to authenticated users.

After login, the API returns a JWT access token. Send this token with protected requests using the Bearer authentication scheme.

Authorization 
Authorization: Bearer YOUR_ACCESS_TOKEN
03

Register

Create a new user account.

POST
/api/v1/auth/register

Request body 

{
    "name": "John Doe",
    "email": "john@example.com",
    "password": "password123"
}

Response 

{
    "access_token": "eyJ...",
    "token_type": "bearer",
    "user": {
        "id": "65f...",
        "name": "John Doe",
        "email": "john@example.com"
    }
}
04

Login

Authenticate an existing user.

POST
/api/v1/auth/login

Request body 

{
    "email": "john@example.com",
    "password": "password123"
}
05

PDF Extraction

Upload a PDF document and extract its text page by page.

POST
/api/v1/pdf/extract
Authentication Required
Content-Type multipart/form-data
File PDF
06

Request

The PDF must be sent as a multipart form field named file. 

POST /api/v1/pdf/extract

Content-Type: multipart/form-data

Authorization: Bearer YOUR_ACCESS_TOKEN

file: document.pdf
07

Response

A successful extraction returns metadata and page-by-page extracted data. 

{
    "success": true,
    "message": "PDF processed successfully.",
    "document_id": "65f...",
    "file": {
        "filename": "document.pdf",
        "size_bytes": 24578,
        "size_mb": 0.023,
        "page_count": 2
    },
    "extraction": {
        "method": "pymupdf",
        "text_extracted": true
    },
    "data": {
        "page_1": {
            "text": "Text from page 1..."
        },
        "page_2": {
            "text": "Text from page 2..."
        }
    }
}
08

Errors

The API returns an HTTP status code together with an error message when a request fails.

Status Meaning
400 Invalid request or invalid PDF
401 Authentication required
413 PDF exceeds 5 MB
422 PDF could not be processed
09

Limits

5 MB Maximum PDF size
100 Maximum pages
PDF Supported file type
10

Examples

cURL 

curl -X POST ^
  http://127.0.0.1:8000/api/v1/pdf/extract ^
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" ^
  -F "file=@document.pdf"

Python 

import requests

url = "http://127.0.0.1:8000/api/v1/pdf/extract"

headers = {
    "Authorization": "Bearer YOUR_ACCESS_TOKEN"
}

with open("document.pdf", "rb") as pdf:

    response = requests.post(
        url,
        headers=headers,
        files={
            "file": pdf
        }
    )

print(response.json())
